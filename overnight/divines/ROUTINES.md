# The four routine prompts

Each routine's whole prompt is one of these. The real instructions live in RULES.md and lanes/<L>.md, so changing the relay means editing those files, never re-pasting prompts.

## Lane A — Divines

Name: `Armarium — Divines`

```
Lane A of the Armarium relay in canon-corpus.
Run: git fetch origin && (git checkout claude/armarium-divines || git checkout -b claude/armarium-divines origin/main) && git pull --rebase origin claude/armarium-divines
Then read overnight/divines/RULES.md and overnight/divines/lanes/A.md, and follow them exactly. Your lane letter is A. Nobody is available to answer questions.
```
