# Primary sources to read (voice research)

On 2026-09-24, three research passes on Sauvé, Isker and Doyle were blocked
by the cloud environment's network policy. Web search worked, but every
page fetch was refused. These are the targets to read once the domains are
allowed, or when run from a normal browser. After reading, upgrade the
**Evidence status** line of each entry in `DEEP-DIVE.md`.

Rules for the upgrade:
- Describe methods. Quote at most a short phrase, cited, and only if read
  on the page.
- Don't copy transcripts into this repo. They're copyrighted.
