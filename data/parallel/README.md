# data/parallel: the parallel-Bible index

`kjv-parallel.tsv` is generated by `pipeline/build_parallel_index.py`; never
hand-edit it. It has one row per KJV verse. Each column names the verse(s)
holding the same text in one version, in that version's own numbering. The
script's docstring says where each column comes from.

## Rights

The index lists verse references only, no scripture text. Its columns do not
all carry the same terms.

- **hebrew, vulgate, douay, brenton**: these columns are derived from
  STEPBible's TVTMS (Tyndale House Versification Mapping), through the maps
  in `data/versification/` (`bhs-kjv.json`, `vulgate-kjv.json`,
  `brenton-kjv.json`). They are licensed **CC BY 4.0**.
  - Attribution: "Data created by www.STEPBible.org based on work at Tyndale
    House Cambridge (CC BY 4.0)".
  - Source: https://github.com/STEPBible/STEPBible-Data
  - STEPBible asks that people be pointed to its repository rather than
    served a mirror (`redistribute_whole: false`). This index is a derived
    subset. It is not TVTMS itself.
- **geneva, tyndale, ylt, darby, asv**: these columns are the house's own
  reading of public-domain texts, by alignment and review
  (`pipeline/build_english_versification.py`). No third-party terms apply.
- **greek_nt**: the Robinson-Pierpont 2018 Greek is public domain. Its
  column is the KJV verse's own reference.
- **kjv, uid**: the KJV verse id and this repository's identifier for it.

A version's verse that holds part of a KJV verse is listed in that verse's
row, so a row is not a claim that the two texts match word for word.
Nearly every map has a `house_rows` section. It records each place where a
review read the texts and corrected the rule-based mapping.
